## Quick Start

```bash
bash <(curl -sSL https://raw.githubusercontent.com/nxtinfinite481-png/IL-AIO-CMD-installer/main/run.sh)
````

The launcher automatically creates a fresh temporary workspace and starts
INFINITE LABS AIO CMD.

## Features

* VPS / VM tools
* Pterodactyl
* PufferPanel
* Wings / Node management
* Blueprint Extensions
* Blueprint Themes
* Docker utilities
* Server administration tools
* Networking utilities
* System utilities
* Menu-driven terminal interface

## Requirements

* Linux VPS or server
* Ubuntu or Debian where required
* Root access for system-level modules
* Internet connection
* Hardware resources appropriate for the selected module

Individual modules may have additional requirements.

---

## Safety

INFINITE LABS AIO CMD contains system-administration and installation scripts
that may modify server configuration.

Review the selected module before running it on a production server.
