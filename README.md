# INFINITE LABS AIO CMD

All-in-one VPS, panel, server, and system management toolkit.

---

### Overview
INFINITE LABS AIO CMD is a professional-grade, terminal-based management suite designed for VPS and server environments. It provides a centralized, modern interface for deploying, managing, and scaling server software, game hosting panels, and system utilities.

### Features

#### Core
* **Premium CLI Dashboard**: Professional terminal interface with real-time system status.
* **Intelligent Routing**: Modular architecture with easy access to all management tools.
* **System Utilities**: Real-time diagnostic and maintenance tools.

#### Panels
A comprehensive suite of panel management modules for one-click or automated deployment:
* **Pterodactyl**: Full panel management, including SSL, phpMyAdmin, and VPS/EGG management.
* **PufferPanel**: Advanced game server management.
* **MythicalDash**: Modern server management interface.
* **Paymenter / Jexactyl / Convoy / Pteroca / Reviactyl / WHMC**: Support for additional billing and panel management modules.

#### System Management
* **Docker Module**: Automated container orchestration and management.
* **Wings / Node**: Dedicated Pterodactyl node/wings service management.
* **Setup VM**: Template-based VPS/VM environment deployment.

#### Themes & Extensions (Blueprint System)
* **66 Blueprint Extensions**: Pre-integrated management for Pterodactyl extensions.
* **20 Blueprint Themes**: Comprehensive theme management system for Pterodactyl.

#### Toolbox & Extras
* **Toolbox**: Includes Cloudflare management, system info, network tunneling (Localtonet), Root access helpers, Tailscale/ZeroTier networking, and terminal utilities.
* **Extras**: Additional utilities including CasaOS, Cockpit, cPanel, and LVM management.
